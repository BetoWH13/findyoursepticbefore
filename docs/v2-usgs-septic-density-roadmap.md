# V2 Roadmap: USGS Septic Density Analysis

## Purpose

Create a stronger V2 data asset only if it answers practical homeowner questions that the current V1 page cannot answer. The goal is not to process USGS data for vanity. The goal is to turn USGS septic-density modeling into plain-English risk signals that help homeowners decide when septic records, 811, or septic-specific locating matter before digging.

## Why It Could Help

- Build authority by moving from a general guide to an interpreted data asset.
- Create a stronger internal hub for state records, before-digging guides, 811 pages, and owned SepticConnect state properties.
- Provide genuinely useful context where historical state septic reliance and modern modeled density differ.
- Make the page harder for competitors to copy because the value comes from cleaned interpretation, not just rewritten copy.

## Practical Questions V2 Should Answer

- Which states or regions show the strongest modern septic-density signal?
- Which states have high localized septic risk even if statewide averages look moderate or low?
- Where does the 1990 Census historical septic baseline agree or disagree with modern USGS density estimates?
- Which before-digging projects become more important in high-density or high-uncertainty areas?
- How should a homeowner use the data without mistaking it for a property-level septic confirmation?

## Required Caveats

- Do not claim the USGS data identifies exact septic systems by address.
- Do not claim the data gives perfect current state-by-state septic usage percentages.
- Explain that the USGS dataset is modeled and summarized by geography.
- Explain that parcel-data gaps can undercount some areas.
- Keep local records, health department files, 811, and professional locating as the property-level next steps.

## Potential V2 Page Structure

1. Plain-English executive summary.
2. Key findings from the USGS septic-density analysis.
3. Historical Census 1990 baseline versus modern USGS density signal.
4. State or regional risk table with homeowner interpretation.
5. Examples of states where localized risk matters more than statewide averages.
6. Before-digging implications for fences, landscaping, trenching, pools, sheds, and additions.
7. Methodology and limitations.
8. Internal links to action guides and state records pages.
9. Contextual links to relevant SepticConnect state properties where useful.

## Deployment Standard

Only build this V2 if the final output is homeowner-readable and decision-oriented. A huge technical table is not enough. The page should feel like a useful public reference and commercial feeder, not a data dump.
